Traced Variable

Traced is a variable grotesque carrying the marks of letterpress newsprint into Latin letters. Move the pointer, and the red plate slips out of register.

Info

Archtype began as a search for letters that match the work, not the other way around. Traced is the first typeface: the rough edge of Korean newspaper letterpress, redrawn as a clean Latin grotesque with five weights on one axis.

Each weight keeps the same shapes. Only the stroke grows, so the type can move from Thin to Bold without any letter changing its mind.
